DFS와 BFS 정리

그래프 탐색의 두 가지 기본 알고리즘.

DFS (깊이 우선 탐색)

스택 또는 재귀로 구현한다. 한 경로를 끝까지 파고든 뒤 되돌아온다.

def dfs(graph, v, visited):
    visited[v] = True
    for u in graph[v]:
        if not visited[u]:
            dfs(graph, u, visited)

BFS (너비 우선 탐색)

큐를 사용해 가까운 노드부터 방문한다. 최단 경로(간선 가중치 동일) 탐색에 적합.

시간복잡도 비교

  • 시간복잡도: O(V + E)
  • 공간복잡도: O(V)
