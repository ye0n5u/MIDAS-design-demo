- images 폴더: 컬러파레트 정보가 담겨있습니다.
- readMe.md: 본 문서입니다.
- html 파일들: 이런 구조입니다~정도로 알아두면 좋습니다.
<br /> <br />

# 페이지 소개
### landing.html
- 내용은 저희가 임의로 수정해도 될 듯합니다!!
- 중앙의 Start Learning 버튼을 클릭하면 login.html 페이지로 이동할 수 있습니다.

### login.html
- 로그인 페이지. 회원가입 등의 기능은 구현되지 않았습니다.
- 중앙의 Login 버튼을 클릭하면 dashboard.html 페이지로 이동할 수 있습니다.

### dashboard.html
- 학습 대시보드 페이지. 학습 시간 등을 확인할 수 있습니다.
- 좌측 최상단의 Lumina Markdown을 클릭하면 landing.html 페이지로 이동할 수 있습니다.
- 좌측 하단의 Set Learning Goals 버튼을 클릭하면 presetting.html 페이지로 이동할 수 있습니다.

### presetting.html
- 학습을 시작하기 전 학습 주제, 작성자, 소속 기관, 학습 시간 등의 정보를 입력할 수 있습니다.
- 정중앙의 Start Learning 버튼을 클릭하면 markdown.html 페이지로 이동할 수 있습니다.

### markdown.html
- 학습을 진행하는 페이지. 중앙 하단의 컨트롤바를 통해 좌측, 우측 사이드바를 열고닫을 수 있습니다. 
- 좌측 사이드바의 dashboard 항목을 클릭하면 dashboard.html 페이지로 이동할 수 있습니다.
<br /> <br />

# 실행 순서
1. **landing.html** 파일을 liveserver로 실행시킨다.
2. Start Learining 버튼을 클릭해 **login.html** 파일로 이동한다.
3. login.html에서 login 버튼을 클릭한다. (정중앙)
4. **dashboard.html**에서 좌측 하단의 set Learning Goals 버튼을 클릭해 **presetting.html** 페이지로 이동한다.
5. presetting 페이지에서 정중앙의 Start Learning 버튼을 클릭, **markdown.html** 페이지로 이동한다.
